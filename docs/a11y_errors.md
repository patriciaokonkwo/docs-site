# Accessibility (a11y) Errors

This document explains common accessibility errors and how to fix them.

## Common Errors
- Missing `alt` text on images
- Non-semantic HTML structure
- Insufficient color contrast

## How to Fix
1. Add descriptive `alt` text to all images.
2. Use semantic HTML elements like `<header>`, `<nav>`, `<main>`, `<footer>`, etc.
3. Ensure color contrast meets WCAG standards.

For more information, refer to the [W3C Accessibility Guidelines](https://www.w3.org/WAI/standards-guidelines/).
