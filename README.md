# Configuration Options

## Environment Variables
- `NODE_ENV`: Set to `development` or `production` to control the environment.

## Configuration File
- `config.json`: Modify this file to customize settings such as API endpoints, timeouts, and other application-specific parameters.

## Example Configuration
```json
{
  "apiEndpoint": "https://api.example.com",
  "timeout": 5000
}
```

## Additional Settings
- Ensure to review any other relevant settings that may affect the application behavior.
